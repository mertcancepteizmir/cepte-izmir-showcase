# Project Memory

## Core
"Cepte İzmir" Super App promo site in Turkish. Primary #3B98F5, white bg, #5BB1FF-#2688F5 gradients.
Glassmorphism, soft shadows, Framer Motion (fade-in/slide-up).
App Store + Google Play butonları kullanılıyor (Hero ve ContactSection üstünde). StoreButtons bileşeninden.
Standart contact form yok; WhatsApp (+90 538 213 55 35). No Twitter.
"Partnerimiz Olun" form uses Supabase Edge Function + Resend.
n8n chatbot integration via webhook.
